# Контроллер мобильді қосымшасы

Excel форматтағы абонент деректерін серверден жүктеп, `кон_знач` мәнін өзгертуге арналған мобильді қосымша.

## Мүмкіндіктер

- **Бір реттік тіркеу** — контроллер нөмірі мен аты-жөні (Figma дизайны бойынша)
- **Басты бет** — бүгінгі күн және көше таңдау
- **Абоненттер кестесі** — тек тіркелген контроллер мен таңдалған көше бойынша
- **Сортировка** — әр баған бойынша (↑/↓)
- **Іздеу** — абонент, ФИО, адрес бойынша
- **кон_знач өзгерту** — `разница = кон_знач - нач_знач`, теріс болса ескерту
- **Автосақтау** — келесі қatarға өткенде алдыңғы қatar сақталады
- **Серверге жіберу** — Excel форматта файл атын өзгертіп upload

## Орнату

### 1. Node.js орнату

[https://nodejs.org](https://nodejs.org) сайтынан Node.js 18+ нұсқасын орнатыңыз.

### 2. Сервер

```bash
cd server
npm install
npm start
```

Сервер `http://localhost:3000` адресінде іске қосылады.  
`server/data/data_09.06.2026.xlsx` — үлгі Excel файлы автоматты түрде жасалады.

### 3. Мобильді қосымша

```bash
cd mobile
npm install
npx expo start
```

Expo Go қосымшасын телефонға орнатып, QR кодты сканерлеңіз.

> **Android эмулятор:** API адресі `10.0.2.2:3000`  
> **iOS симулятор:** API адресі `localhost:3000`  
> **Нақты телефон:** `.env` файлында компьютер IP-ін көрсетіңіз:

```
EXPO_PUBLIC_API_URL=http://192.168.1.100:3000
```

## API

| Метод | URL | Сипаттама |
|-------|-----|-----------|
| GET | `/api/health` | Сервер статусы |
| GET | `/api/download` | Соңғы Excel файлды жүктеу |
| GET | `/api/download/:date` | Белгілі күн бойынша файл |
| POST | `/api/upload` | Excel файлды жіберу (multipart) |

## Excel форматы

```
дата    09.06.2026

контроллер  абонент  Фио   адрес         нач_знач  кон_знач  разница
1           1001     фио1  ул Сакен 1    0         0         0
```

Жіберілген файл аты: `data_09.06.2026_controller_1_completed.xlsx`
